# Identity photo placeholders (specimens)

Professional placeholder images for the identity-card layouts (member card,
registration review dossier, QR-scan card, directory). They are neutral
head-and-shoulders silhouettes on a clean studio background, in three tones, each
watermarked "SPECIMEN ADSUM".

These are test and design assets only. They contain no real person and no
personal data: never present a specimen as a member's actual photo. Use them to
check the visual rendering of the identity-card views, or as sample uploads when
exercising the photo pipeline in a development environment.
